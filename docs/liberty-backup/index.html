Personal recovery tool

LIBERTY Backup

LIBERTY Backup stores encrypted recovery copies of its owner's approved application data in the owner's Google Drive account. It is a personal tool, not a public backup service, and does not accept registrations.

How it works

The tool runs on the owner's private server. Google Drive authorization allows it to create, read, verify, and maintain backup files. The owner approves the backup contents and process before uploads are enabled.

The intended process encrypts backup contents, filenames, and folder names on the private server before uploading them through rclone. Local backup copies are managed separately.
